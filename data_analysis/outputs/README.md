## 💾 Preprocessed Datasets & ML Artifacts

| File Name | Format | Purpose |
|---|---|---|
| `X_train.csv` | CSV | Cleaned feature matrix for training (1200 rows × 13 features) |
| `X_test.csv` | CSV | Cleaned feature matrix for evaluation (300 rows × 13 features) |
| `X_train_scaled.csv` | CSV | Standardized feature matrix (zero mean, unit variance) |
| `X_test_scaled.csv` | CSV | Standardized test matrix using training scalar parameters |
| `y_train.csv` | CSV | Encoded integer scheme labels for training set |
| `y_test.csv` | CSV | Encoded integer scheme labels for test set |
| `preprocessed_full.csv` | CSV | Complete unified dataset with raw + engineered + encoded columns |
| `feature_importance.csv` | CSV | Tabular rankings of feature contributions and percentages |
| `model_comparison_results.csv` | CSV | Quantitative metrics (Acc, F1, Prec, Rec, CV, Time) across all models |
| `preprocessing_encoders.pkl` | Pickle | Serialized dictionary of fitted `LabelEncoder` objects |
| `scaler.pkl` | Pickle | Serialized `StandardScaler` fitted on training features |
| `preprocessing_config.json` | JSON | Machine-readable schema describing features, classes, and parameters |
