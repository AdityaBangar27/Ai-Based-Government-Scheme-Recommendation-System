# 🗄️ Model Artifacts Store

## Overview
This directory serves as the **shared model repository** storing production-ready serialized model binaries and encoders utilized across inference engines and external services.

---

## 📁 Artifact Manifest

| File | Format | Description |
|---|---|---|
| `scheme_model.pkl` | Joblib / Pickle | Serialized `RandomForestClassifier` (100 estimators, max depth 15) |
| `encoders.pkl` | Joblib / Pickle | Dictionary of fitted `LabelEncoder` objects for categorical features |
| `model_config.json` | JSON | Feature column ordering and model metadata for runtime verification |

---

## ⚙️ Model Specification (`model_config.json`)
```json
{
    "feature_columns": [
        "age",
        "income",
        "gender",
        "occupation",
        "education",
        "category",
        "state",
        "disability_status",
        "farmer_status",
        "student_status",
        "employment_status"
    ],
    "n_estimators": 100,
    "model_type": "RandomForestClassifier"
}
```

These artifacts are generated by `ml_model/train_model.py` and read by `ml_model/predict.py`.
