## 🚀 QUICK START (3 Steps)

### 1. Start Backend
```bash
cd server
npm install
npm run dev
```
Runs on: http://localhost:5000

### 2. Start Frontend
```bash
cd client
npm install
npm start
```
Runs on: http://localhost:3000

### 3. Train ML Model (First Time Only)
```bash
cd ml_model
pip install -r requirements.txt
python train_model.py
```

**Then visit http://localhost:3000** ✨
